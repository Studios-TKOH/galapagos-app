# Módulo Operator

**Código:** `src/app/operator`, `src/components/operator`.

Responsabilidad: operación de salidas y cupos. Dirección futura: manifiesto, check-in/scanner y redención offline.

Baseline: edición de cupos mediante RPC. Falta ownership robusto por operador/organización y creación completa de salidas.

Invariantes: operador solo ve/modifica recursos asignados; acciones de inventario y redención se auditan; UI móvil/táctil es prioritaria.
